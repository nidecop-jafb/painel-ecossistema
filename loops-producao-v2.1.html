4 Modos Oficiais

Intervalo fixo

/loop INTERVALO PROMPT

Executa o prompt em intervalos regulares (cron). Ideal para polling de CI, builds e deploys.

/loop 5m verificar build

Dinâmico

/loop PROMPT

Claude decide o intervalo (1–60 min) com base no estado observado. Para em stop: true.

/loop gerar TT de T07-T12

Objetivo

/goal CONDIÇÃO

Trabalha turno a turno até a condição ser verificada por modelo rápido. Sem timer.

/goal validar_tt.py PASS 15/15

Manutenção

/loop (bare)

Continua trabalho pendente, tende PRs, faz cleanup. Customizável via .claude/loop.md.

/loop ou /loop 15m

Fluxo Recomendado por Onda

Regra geral: Use /goal para OAs individuais que precisam de gate (TT, FA, TR) — o loop para quando o critério é atingido. Use /loop PROMPT (dinâmico) para produção em lote de OAs leves dentro de uma onda (MC, CD, PP, TN, IT). Use /loop (manutenção) entre sessões para cleanup e PR. Use /loop INTERVALO (fixo) para monitorar processos externos (compilação Tectonic, importação Moodle).

Física Conceitual 1 16 OAs

C2 Camada 2 (Briefing) Dinâmico ▶ 
/loop Gerar Camada 2 para T07-T12. Ler temas-trilhas-topicos-v3.docx, acionar skill abertura-trilha para cada trilha. Salvar cada C2 e seguir para a próxima. Parar após T12.

Dinâmico porque o Claude gera 6 C2 em sequência, decidindo o ritmo. Cada C2 demora ~5 min — sem necessidade de timer fixo.

  • 6 arquivos T07-Camada2-v1.md a T12-Camada2-v1.md criados
TT Texto Temático Objetivo ▶ 
/goal python _scripts/validar_tt.py T07 retorna PASS 15/15 e python _scripts/checklist_pre_entrega.py T07 TT retorna 10/10 PASS

O TT é o OA mais complexo (15 checks). /goal garante que o Claude itera até todos os checks passarem — sem entrega prematura.

  • validar_tt.py PASS 15/15
  • checklist_pre_entrega.py PASS 10/10
  • Par .md/.docx com mesma v{N}
IT Imagens Temáticas Dinâmico ▶ 
/loop Gerar IT para T07-T12 em lote. Acionar skill imagens-tematicas-lote para cada trilha. Produzir 2 arquivos por trilha (-pt- e -Gemine). Parar após gerar 12 arquivos (6 trilhas x 2).

Dinâmico porque IT é geração de texto (prompts), não compilação. O Claude avança trilha por trilha e para sozinho.

  • 12 arquivos .txt criados (6x -pt- + 6x -Gemine)
  • 12 IT por trilha (IT-00 a IT-11) em cada arquivo
MD Resumo em Áudio Dinâmico ▶ 
/loop Gerar MD (resumo em áudio) para T07-T12. Acionar skill resumo-em-audio, ler TT aprovado de cada trilha. Produzir .docx + NotebookLM-fonte .txt. Parar após T12.

OA leve, ~10 min/trilha. O loop dinâmico processa as 6 trilhas em sequência sem intervenção.

MC Mapa Conceitual Dinâmico ▶ 
/loop Gerar MC para T07-T12. Acionar skill mapa-conceitual, ler TT de cada trilha. Salvar .md na Pre_Aula/. Parar após T12.

Lote de OAs leves — dinâmico é ideal. Claude gera e avança sem polling.

CD Cartões Didáticos Dinâmico ▶ 
/loop Gerar CD para T07-T12. Acionar skill cartoes-didaticos, extrair conceitos-chave do MC e TT. Salvar .md + .xml. Parar após T12.

Depende do MC (gerado no passo anterior). Mesmo padrão dinâmico de lote.

PP Ponto de Partida Dinâmico ▶ 
/loop Gerar PP para T07-T12. Acionar skill ponto-de-partida. Produzir .md + 3 variantes GIFT/XML Moodle. Validar com validar_banco.py. Parar após T12.

Quiz diagnóstico — geração + exportação Moodle em lote. Dinâmico com validação integrada.

TN Testinho Objetivo ▶

TN é complexo (20 questões, 5 blocos, 4 variantes, codificação E#). /goal garante que o banco passa na validação antes de entregar.

IG Infográfico Dinâmico ▶

Recomendação: Criar um .claude/loop.md customizado que substitua o comportamento padrão do /loop (bare) por um workflow específico do projeto Trilhas:
  1. Verificar OAs pendentes no status de produção (Citacoes_Trilhas_T0A-T60.xlsx)
  2. Rodar checklist_pre_entrega.py --all para detectar OAs com FAIL
  3. Corrigir OAs com FAIL na ordem de prioridade da onda atual
  4. Sugerir próximo OA da sequência da onda
  5. Rodar validar_banco.py --all para verificar integridade do banco central
